# OpenCode Project Sessions

在 OpenCode Desktop 中按项目查找和切换会话。把分散在不同项目、本机和远程服务器上的对话放在一个列表里，快速回到需要继续的工作。

## 能做什么

- **按项目浏览**：当前项目优先展示，其他项目可展开查看会话，不限于已打开的标签页。
- **快速搜索**：按项目名、会话标题或目录搜索，支持多个关键词。
- **回到当前工作**：快速定位当前会话，或筛选“当前项目”。
- **保留浏览状态**：记住项目展开状态、展示数量和筛选范围。
- **融入 OpenCode**：支持顶部标签页和侧边栏模式，界面跟随语言和主题，提供中文与英文。

## 安装

适用于 **OpenCode Desktop 2.2.5**。其他版本可能需要适配。

下载或克隆本仓库，仓库已包含构建好的插件。

在全局配置 `~/.config/opencode/opencode.json` 或 `opencode.jsonc` 的 `plugins` 数组中追加插件目录的绝对路径。保留已有配置，将示例路径替换为实际下载位置：

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "/absolute/path/to/opencode-project-sessions",
  ],
}
```

保存后自动加载，无需重启，也无需额外配置 API key。可在 **Settings → Extensions → Plugins** 中停用插件。

## 打开项目会话

- **快捷键**：macOS 按 **⌘⇧S（Command + Shift + S）**；Windows/Linux 按 **Ctrl + Shift + S**。
- **会话页面**：点击顶部“摘要”右侧的文件夹按钮。
- **命令面板**：选择 **打开项目会话 / Open project sessions**，主页也可使用。

可在 **Settings → Shortcuts → Navigation** 中修改或禁用快捷键。文件夹按钮的悬浮提示会显示当前快捷键。

## 浏览与切换

点击项目名称展开或折叠，点击会话切换。会话较多时，点击“显示更多会话”；搜索时展开匹配的项目并显示全部匹配会话。

列表加载完成后，自动展开当前项目并定位当前会话，保留搜索框焦点和已保存的筛选范围。当前会话不在列表中时，恢复上次的滚动位置。若加载完成前已开始交互，则保留用户的浏览状态，跳过自动展开和定位。

当前项目和当前会话分别置顶，其余项目按组内最新会话的更新时间降序排列，项目内其余会话也按更新时间降序排列。初始加载期间持续排序；加载完成或开始浏览后，已有行保持原顺序，新项追加到末尾。重新打开时重新排序，搜索仅过滤结果，不改变顺序。

悬浮或聚焦项目行时，右侧显示新建会话图标，替换服务器名和会话数。点击图标，在该项目对应的服务器和根目录下创建并打开新会话。

悬浮或聚焦会话行时，右侧显示归档和删除图标，替换更新时间，保留运行状态。归档后会话从列表移除；删除前需要确认，删除操作无法撤销。

也可以全程使用键盘：

| 操作 | 按键 |
| --- | --- |
| 从搜索框进入列表 | ↓ |
| 上下选择（焦点在列表行） | ↑ / ↓ |
| 移到列表首尾（焦点在列表行） | Home / End |
| 展开或折叠项目（焦点在项目行） | → / ← |
| 返回项目标题（焦点在会话行） | ← |
| 打开会话（焦点在会话行） | Enter |
| 在输入框、列表和操作按钮间切换焦点 | Tab / Shift+Tab |
| 执行新建、归档或删除（焦点在对应按钮） | Enter / Space |
| 关闭弹窗 | Esc |

## 使用范围

- 仅展示未归档的主会话，不包含子智能体会话。
- 会话状态取决于 OpenCode 已同步的信息，“待授权 / 待输入”提示不能替代原生通知。
- 服务器断开时保留已加载的会话，连接恢复后可重试刷新。
- 插件不发送消息，也不替换原生侧边栏。
